Agent Fabric exposes a public API (72 endpoints) and an internal control-plane API (21 endpoints). The service runs on port 3001 and is accessed through the xFabric edge layer.

## Authentication

All requests require an xFabric JWT or API key:

```bash
Authorization: Bearer YOUR_TOKEN
```

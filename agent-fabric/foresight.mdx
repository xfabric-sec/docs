Foresight is xFabric's automated code review agent. It analyzes pull requests and posts inline findings on correctness, security, performance, and code quality.

## How it works

1. A pull request is opened or updated on GitHub
2. GitHub sends a webhook to xFabric (`POST /api/webhook/github/pr`)
3. Foresight queues the review and analyzes the diff against the full repository context
4. Findings are posted as inline comments on the PR

## Setting up Foresight

<Steps>
  <Step title="Connect your repository">
    Link your GitHub repository in the xFabric dashboard under **Settings > Integrations > GitHub**.
  </Step>
  <Step title="Configure webhooks">
    xFabric automatically registers a webhook on your repository for pull request events. You can also use the provider-agnostic webhook endpoint for other Git providers.
  </Step>
  <Step title="Open a pull request">
    Foresight runs automatically. Review its findings in the PR conversation tab.
  </Step>
</Steps>

## Webhooks

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/webhook/github/pr` | GitHub-specific PR webhook receiver |
| `POST` | `/api/webhook/pr` | Provider-agnostic PR webhook receiver |

## API endpoints

### Start a review

```bash
# Synchronous — blocks until review completes
curl -X POST https://api.xfabric.io/fabric/api/simu-agent/v1/code-review/start \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"repo": "my-org/my-repo", "pr_number": 42}'
```

### Start an async review

```bash
# Returns immediately with a job ID
curl -X POST https://api.xfabric.io/fabric/api/simu-agent/v1/code-review/start-async \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"repo": "my-org/my-repo", "pr_number": 42}'

# Poll for status
curl https://api.xfabric.io/fabric/api/simu-agent/v1/code-review/status/{job_id} \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Queue status

Check how deep the review queue is:

```bash
curl https://api.xfabric.io/fabric/api/simu-agent/v1/queue/status \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Review endpoints summary

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/simu-agent/v1/code-review/start` | Synchronous review |
| `POST` | `/api/simu-agent/v1/code-review/start-async` | Async review (returns job ID) |
| `GET` | `/api/simu-agent/v1/code-review/status/{job_id}` | Poll async review status |
| `GET` | `/api/simu-agent/v1/queue/status` | Review queue depth and running count |

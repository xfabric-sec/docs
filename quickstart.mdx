This guide walks you through setting up xFabric and connecting it to your first project.

## Prerequisites

Before you begin, you need:

- An xFabric account
- Access to a Git repository you want to analyze
- An API key (generated from your dashboard)

## Get started

<Steps>
  <Step title="Sign up">
    Create your xFabric account and generate an API key from the dashboard.
  </Step>
  <Step title="Connect a repository">
    Link your GitHub repository to xFabric. This enables code review with Foresight and topology mapping with the World Model.
  </Step>
  <Step title="Run your first scan">
    Trigger a code review or simulation from the dashboard, or let xFabric run automatically on your next pull request.
  </Step>
</Steps>

This guide walks you through ingesting a document and running your first query.

## Prerequisites

- An xFabric API key
- A document to ingest (Markdown, PDF, or DOCX)

## Ingest a document

<Steps>
  <Step title="Create a collection">
    Collections isolate memories by project or domain. Creating a collection is idempotent.

    ```bash
    curl -X POST https://api.xfabric.io/v1/memory/collections \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "my-project"}'
    ```
  </Step>
  <Step title="Upload a document">
    Ingestion is asynchronous. You get a job ID and queue position back immediately.

    ```bash
    curl -X POST https://api.xfabric.io/v1/memory/ingest \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -F "file=@./docs/architecture.md" \
      -F "collection=my-project"
    ```

    Response:
    ```json
    {
      "job_id": "abc123",
      "status": "queued",
      "queue_position": 1
    }
    ```
  </Step>
  <Step title="Check ingestion status">
    Poll until the job completes:

    ```bash
    curl https://api.xfabric.io/v1/memory/ingest/abc123 \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    Response when complete:
    ```json
    {
      "job_id": "abc123",
      "status": "completed",
      "stage": "done",
      "filename": "architecture.md",
      "records": 1,
      "segments": 12,
      "memories_added": 47,
      "memories_updated": 3
    }
    ```
  </Step>
  <Step title="Retrieve memories">
    Search for relevant memories:

    ```bash
    curl -X POST https://api.xfabric.io/v1/memory/retrieve \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"query": "authentication flow", "collection": "my-project"}'
    ```
  </Step>
  <Step title="Ask a question">
    Get a grounded answer with citations:

    ```bash
    curl -X POST https://api.xfabric.io/v1/memory/ask \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"question": "What database does the auth service use?", "collection": "my-project"}'
    ```

    The `/ask` endpoint is also async. Poll the returned job ID for the answer.
  </Step>
</Steps>

## Python API

You can also use Agent Memory as a Python library:

```python
from agent_memory import Config, Normalizer, Segmenter, MemoryManager, PolicyRetriever

config = Config.load()
normalizer = Normalizer(config)
segmenter = Segmenter(config)
manager = MemoryManager(config)
retriever = PolicyRetriever(config)

# Ingest
record = normalizer.normalize("./docs/architecture.md")
segments = segmenter.segment(record)
manager.store(segments)

# Retrieve
result = retriever.retrieve("authentication flow")
for memory in result.memories:
    print(f"{memory.title}: {memory.text}")
```

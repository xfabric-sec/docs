Connectors pull documents from external sources into Agent Memory. Each connector handles authentication, source listing, and document ingestion for its platform.

## Available connectors

| Connector | Auth method | Supported content |
|---|---|---|
| **Notion** | Integration token | Pages, databases, nested hierarchies |
| **Google Drive** | Service account | Docs, Sheets, PDFs, Slides, text files |
| **Canva** | OAuth PKCE | Designs exported as PDF |

## Connector API

### List connectors

```bash
curl https://api.xfabric.io/v1/memory/connectors \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Returns each connector's ID, display name, whether credentials are configured, and the credential type.

### Configure credentials

```bash
# Check credential status
curl https://api.xfabric.io/v1/memory/connectors/{connector_id}/credentials \
  -H "Authorization: Bearer YOUR_API_KEY"

# Upload credentials
curl -X POST https://api.xfabric.io/v1/memory/connectors/{connector_id}/credentials \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "credentials=@service-account.json"

# Remove credentials
curl -X DELETE https://api.xfabric.io/v1/memory/connectors/{connector_id}/credentials \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### List available sources

Browse what's available to ingest:

```bash
curl -X POST https://api.xfabric.io/v1/memory/connectors/{connector_id}/list \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"params": {}}'
```

### Ingest from a connector

```bash
curl -X POST https://api.xfabric.io/v1/memory/connectors/{connector_id}/ingest \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"params": {"source_id": "..."}, "collection": "my-project"}'
```

Returns a job ID. Poll for progress:

```bash
curl https://api.xfabric.io/v1/memory/connectors/jobs/{job_id} \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Notion

### Setup

<Steps>
  <Step title="Create an integration">
    Go to [notion.so/my-integrations](https://notion.so/my-integrations) and create a new internal integration. Copy the integration token.
  </Step>
  <Step title="Share pages with the integration">
    In Notion, open each page or database you want to ingest and share it with your integration.
  </Step>
  <Step title="Upload the token">
    ```bash
    curl -X POST https://api.xfabric.io/v1/memory/connectors/notion/credentials \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -F "token=YOUR_NOTION_TOKEN"
    ```
  </Step>
</Steps>

### Source scoping

When listing sources, you can scope by page ID to ingest a specific subtree. The connector follows the page hierarchy and respects depth limits.

**Supported Notion blocks:** paragraphs, headings, lists, code, quotes, callouts, tables, toggles, dividers, and embedded content. Databases are exported with their properties.

**Limitations:** Comments, page comments, and some embed types are not captured.

## Google Drive

### Setup

<Steps>
  <Step title="Create a service account">
    In Google Cloud Console, create a service account and download the JSON key file.
  </Step>
  <Step title="Share folders">
    Share the Google Drive folders you want to ingest with the service account email.
  </Step>
  <Step title="Upload credentials">
    ```bash
    curl -X POST https://api.xfabric.io/v1/memory/connectors/google-drive/credentials \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -F "credentials=@service-account.json"
    ```
  </Step>
</Steps>

### Supported files

Google Docs, Sheets, Slides (exported as text), PDFs, plain text, and Markdown files. Shared drives are supported. Pass the drive ID in the list params.

## Canva

### Setup

Canva uses OAuth PKCE for authentication:

<Steps>
  <Step title="Start the OAuth flow">
    ```bash
    curl -X POST https://api.xfabric.io/v1/memory/connectors/canva/auth/start \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```
    This returns an authorization URL. Open it in a browser to authenticate.
  </Step>
  <Step title="Complete authorization">
    After authorizing, Canva redirects to the callback endpoint (`/connectors/canva/callback`), which stores the credentials automatically.
  </Step>
</Steps>

### How it works

Canva designs are exported as PDF and then processed through the standard PDF ingestion pipeline. This means complex designs with text, tables, and images are captured.

**Limitations:** Non-text visual elements (illustrations, photos) are not extracted as memories.

## Adding a new connector

Connectors implement the `BaseConnector` interface with three methods:

1. **`list_sources(params)`**: return available documents/folders
2. **`ingest(params, collection)`**: download and ingest documents
3. **Credential management**: store and validate authentication

New connectors are registered in the `ConnectorRegistry` and automatically exposed through the connector API endpoints.

Agent Memory is configured via a YAML file (`default.yml`) with environment variable overrides. The config is loaded at startup and can be partially updated at runtime via the API.

## Environment variables

| Variable | Description |
|---|---|
| `RESETS_ENABLED` | Enable the `/internal/reset` endpoint |
| `AZURE_OPENAI_API_KEY` | Azure OpenAI API key |
| `AZURE_OPENAI_ENDPOINT` | Azure OpenAI endpoint URL |
| `OPENAI_API_KEY` | OpenAI API key |

YAML values can reference environment variables with the `!env` tag:

```yaml
providers:
  azure_llm:
    api_key: !env AZURE_OPENAI_API_KEY
    endpoint: !env AZURE_OPENAI_ENDPOINT
```

## Runtime config API

```bash
# Get current config
curl https://api.xfabric.io/v1/memory/config \
  -H "Authorization: Bearer YOUR_API_KEY"

# Update config at runtime
curl -X PATCH https://api.xfabric.io/v1/memory/config \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"retrieval": {"max_steps": 8}}'

# Add/update a provider
curl -X POST https://api.xfabric.io/v1/memory/config/providers \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "openai", "api_key": "sk-..."}'

# Reload LLM config from file
curl -X POST https://api.xfabric.io/v1/memory/internal/llm-config/reload \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Full config reference

### Providers

Named LLM provider profiles. Supports Azure OpenAI, OpenAI, Anthropic, Bedrock, Vertex AI, and Gemini.

```yaml
providers:
  azure_llm:
    api_key: !env AZURE_OPENAI_API_KEY
    endpoint: !env AZURE_OPENAI_ENDPOINT
  azure_embedding:
    api_key: !env AZURE_OPENAI_API_KEY
    endpoint: !env AZURE_OPENAI_ENDPOINT
  openai:
    api_key: !env OPENAI_API_KEY
```

### Domain

```yaml
domain: general  # options: default, finance, general, legal, math, personal
```

### Collection

```yaml
collection: default  # default collection name
```

### Normalization

```yaml
normalization:
  pdf:
    engine: docling  # docling | marker | hybrid
    docling:
      do_ocr: true
      table_mode: accurate
    marker:
      use_llm: false
      force_ocr: false
    hybrid:
      text_threshold: 0.8
```

### Segmentation

```yaml
segmentation:
  chunk_size: 2000    # max chars per segment
  overlap: 200        # overlap between segments
  min_chars: 500      # minimum segment size
```

### Memory extraction

```yaml
memory:
  similarity_threshold: 0.90  # deduplication threshold
  batch_size: 64              # extraction batch size
  llm: gpt-5.4-mini          # extraction model
  embedding: text-embedding-3-small
  semantic_storage: chromadb  # chromadb | pgvector
  bm25_storage: file          # file | postgres
  cue_anchor_storage: file    # file | postgres
  episodic:
    enabled: true
    mode: extracted
```

### Question answering

```yaml
qa:
  llm: gpt-5.4-mini
  max_context_chars: 4000
  max_concurrent_jobs: 10
```

### Judge

```yaml
judge:
  llm: gpt-5.5
```

### Retrieval

```yaml
retrieval:
  type: policy              # policy | semantic | hybrid_retriever | ...
  budget_type: steps
  max_steps: 5
  initial_fetch_count: 15
  tools:
    - expand
    - refine_query
    - decompose_query
    - terminate
```

### Ingestion

```yaml
ingestion:
  max_concurrent_jobs: 2
```

### Storage backends

```yaml
storage:
  pg_pool_size: 32
  records: file      # file | postgres
  segments: file     # file | postgres
cache: disk
```

### Retry

```yaml
retry:
  multiplier: 2
  min_wait: 1
  max_wait: 4
  max_attempts: 10
  jitter: 5
  timeout: 120
```

## Storage backends

Agent Memory supports pluggable storage backends per component:

| Component | Local | Production |
|---|---|---|
| **Records** | File-based | PostgreSQL |
| **Segments** | File-based | PostgreSQL |
| **Semantic search** | ChromaDB | pgvector |
| **BM25 index** | File-based | PostgreSQL |
| **Cue anchors** | File-based | PostgreSQL |
| **Cache** | Disk | Disk |

For production, use PostgreSQL + pgvector for all backends. Set the storage config and provide the connection string via environment variables.

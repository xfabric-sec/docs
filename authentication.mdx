## Sign-in Methods

Cielara supports two authentication methods:

### Email and Password

The default method. Users sign in with their email and a password set during registration or invitation.

### Google Workspace SSO

Cielara supports single sign-on through Google Workspace using OpenID Connect (OIDC). When SSO is enabled, users from your Google Workspace domain are redirected to Google's login page instead of entering a password.

To configure Google SSO, navigate to **Authentication > Google** (`/admin/authentication/google`) and follow the setup steps.

The OIDC flow uses PKCE (Proof Key for Code Exchange) to prevent authorization code interception, a browser-bound state parameter to prevent CSRF, and nonce replay protection.

### SAML

Cielara also supports SAML-based SSO for organizations that use identity providers other than Google. Configure SAML at **Authentication > SAML** (`/admin/authentication/saml`).

## How Login Resolution Works

When a user enters their email on the login page, Cielara checks which authentication method applies to that email domain. If SSO is configured for the domain, the user is redirected to the identity provider. Otherwise, the standard email/password form appears.

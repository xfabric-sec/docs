The Connections page is where all integrations live. Click **Connections** in the sidebar to open it. The page uses a list-and-detail layout: a left pane shows your connections grouped by type, and a right pane shows details for the selected connection.

A type filter dropdown at the top lets you narrow the list to a specific group.

## Connection groups

| Group | Providers | What they provide |
|---|---|---|
| **Cloud** | AWS, GCP, Azure | Accounts, regions, projects, subscriptions, resource discovery |
| **Clusters** | Kubernetes, GKE, EKS, AKS | Cluster topology, namespaces, workloads, pods |
| **Source code** | GitHub, Azure DevOps | Repository access, PR webhooks for Foresight code review |
| **Logs** | Elasticsearch, Dynatrace | Log indices, environment metrics |
| **Alerts** | PagerDuty, AlertManager | Incidents, on-call, Prometheus alerts |
| **Secrets** | HashiCorp Vault | Cluster and namespace secrets |
| **Workplace** | Slack, Jira, Confluence, Notion, Canva, Google Drive | Notifications, issue linking, documentation, knowledge base documents |

## Adding a connection

Click the **+** button to open the provider catalog. Entries are organized by group, each with a short description: AWS (accounts, regions, resources), GCP (projects and folders), Azure (tenants and subscriptions), GitHub (organisations and repositories), Azure DevOps (repos and pipelines), PagerDuty (incidents and on-call), AlertManager (Prometheus alerts), Elasticsearch (log indices), Dynatrace (environment metrics and logs), HashiCorp Vault (clusters and namespaces), Slack (incident notifications), Jira (work items), Confluence (spaces and pages), Notion (runbooks and wikis), Canva (designs and presentations), and Google Drive (docs in a folder).

Select a provider and follow its setup flow. Cloud and source code connections typically require OAuth or API credentials. Workplace tools each have their own configuration panel. See the [setup connections guide](/guides/setup-connections) for field-by-field instructions.

## Workplace tools

Workplace integrations (Slack, Jira, Confluence, Notion, Canva, Google Drive) are singleton connections with dedicated setup panels. The Communications tab (`?tab=communications`) handles Slack. The Ticketing tab (`?tab=ticketing`) handles Jira. The Documentation tab (`?tab=documentation`) handles Confluence, Notion, Canva, and Google Drive; these also serve as knowledge base connectors, pulling documents into Agent Memory for the Memory Explorer and Ask Cielara.

You can deep-link to an individual tool with `?tool=slack`, `?tool=jira`, `?tool=confluence`, etc.

## Additional panels

The API Keys tab (`?tab=api-keys`) lets you create and manage API keys for programmatic access. The OAuth Clients tab (`?tab=oauth-clients`) lets you manage OAuth client configurations.

## GitHub App callback

When connecting GitHub, the OAuth flow redirects through `/connections/github-app-callback` to complete the authorization. This happens automatically during setup.

## Foresight settings

The Connections page also shows a summary of your Foresight configuration: GitHub App status, personal GitHub sign-in availability, and the list of connected repositories. This appears in the source code connection detail view.

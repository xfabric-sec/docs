All xFabric products run on the platform. It has six services behind a shared edge layer, with multi-cloud support (AWS, Azure, GCP) and a graph-based entity model supporting 78+ entity types.

## Capabilities

- **Multi-cloud inventory**: discover and scan resources across AWS, Azure, GCP, and Kubernetes via cloud provider plugins
- **Graph-based modeling**: FalkorDB entity graph with 78+ entity types and relationship traversal
- **Authentication**: JWT-based auth with Google Workspace SSO (OIDC), RBAC with Admin and User roles
- **Integrations**: GitHub, Slack, Jira, Confluence, Notion, Google Drive, Canva
- **MCP server**: AI-native tool access via the Model Context Protocol
- **LLM gateway**: proxy to configured LLM providers

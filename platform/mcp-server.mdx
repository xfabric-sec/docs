---
title: "MCP server"
description: "Model Context Protocol server — AI-native tool access to xFabric capabilities."
---

The xFabric MCP server exposes platform capabilities as tools that AI assistants can call via the [Model Context Protocol](https://modelcontextprotocol.io). It runs on port 8888 and authenticates with a static bearer token.

## Available tools

### Memory tools

| Tool | Description |
|---|---|
| `search_memories` | Search the knowledge base for relevant memories |
| `ask_memories` | Ask a natural-language question and get a grounded answer |
| `list_memory_collections` | List available memory collections |

### Simulation tools

| Tool | Description |
|---|---|
| `list_scenarios` | List available simulation scenarios |
| `get_scenario` | Get details of a specific scenario |
| `trigger_scenario` | Run a simulation scenario |
| `trigger_incident_rca` | Trigger root cause analysis for an incident |

### Code review tools

| Tool | Description |
|---|---|
| `run_code_review` | Run a code review on a pull request |
| `list_pr_reviews` | List past PR reviews |
| `get_pr_review` | Get details of a specific review |
| `run_pr_simulation` | Run a simulation against a PR's changes |

### Incident tools

| Tool | Description |
|---|---|
| `list_incidents` | List known incidents |
| `get_incident` | Get details of a specific incident |

### World Model tools

| Tool | Description |
|---|---|
| `query_world_model` | Query the service topology in natural language |
| `start_inquiry` | Start a deep inquiry about your infrastructure |
| `check_inquiry` | Check the status of a running inquiry |

### Local tools

| Tool | Description |
|---|---|
| `get_user_context` | Get the current user's context and permissions |
| `show_button` | Render a button with a URL in the AI assistant's UI |

## Async tool flow

Some tools (simulations, code reviews, deep inquiries) run asynchronously:

1. The AI assistant calls the tool (e.g., `run_code_review`)
2. The MCP server returns a job ID immediately
3. The assistant polls for results using the corresponding status tool
4. Once complete, results are returned to the assistant

## Authentication

All MCP tool calls require a static bearer token in the request header:

```
Authorization: Bearer YOUR_MCP_TOKEN
```

Configure the token in your MCP client's server settings.

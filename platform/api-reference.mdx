The xFabric platform exposes two API surfaces: the **insights-backend** (core API on port 8080) and the **admin-backend** (identity and management on port 8100).

## Authentication

All requests require a JWT or API key:

```bash
Authorization: Bearer YOUR_TOKEN
```

See the [Authentication](/platform/authentication) page for details on obtaining tokens.

## admin-backend (port 8100)

### Public endpoints (no auth required)

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/iam/login` | Email/password login |
| `POST` | `/api/iam/login/options` | Resolve auth method for an email |
| `POST` | `/api/iam/signup` | Create a new account |
| `GET` | `/saml/discovery` | SAML discovery |
| `GET` | `/saml/metadata` | SAML metadata |
| `POST` | `/saml/acs` | SAML assertion consumer service |

### Authenticated endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/iam/users` | List users |
| `POST` | `/api/iam/users` | Create user |
| `PUT` | `/api/iam/users/:id` | Update user |
| `DELETE` | `/api/iam/users/:id` | Delete user |
| `GET` | `/api/iam/roles` | List roles |

### System administration

System reset requires a 3-layer guard (admin role + confirmation token + feature flag).

| Method | Path | Description |
|---|---|---|
| `POST` | `/server-admin/reconcile/` | Reconcile system state |
| `PUT` | `/server-admin/config-states/` | Update config |
| `POST` | `/api/system/reset` | System reset (guarded) |

</Info>

Cielara needs at least one LLM provider configured to run code reviews, simulations, the AI assistant, and knowledge base question answering. The Models page lets admins set up and manage these providers.

  <img src="/images/models.png" alt="Models configuration" />
</Frame>

## Provider catalog

The page shows a catalog of available LLM providers. Select a provider to configure its credentials (API key, endpoint, etc.).

## Configuring a provider

1. Select a provider from the catalog
2. Enter the required credentials
3. Click **Test** to verify connectivity (Cielara sends a test request to the provider)
4. Save the configuration

Once saved, the provider appears in the configured list. You can activate or deactivate providers, and set which provider handles embedding separately from which handles completions.

## Setup status

A setup status indicator (also visible to non-admin users at a read-only endpoint) shows whether any LLM provider is configured. Until a provider is active, AI features are unavailable.

## Embedding configuration

The embedding config section lets you choose the embedding model (e.g., text-embedding-3-small or text-embedding-3-large) used by the knowledge base for document indexing and semantic search.

## Budget controls

The budget section lets admins set spending limits on LLM usage. Set a spending cap for a time period under budget config, and review current spend, per-model breakdowns, and spend logs in the spend dashboard.

## Multiple providers

You can configure multiple providers and switch between them. Cielara supports direct OpenAI, Azure OpenAI, and a LiteLLM gateway mode. Switching providers at runtime does not require restarting services.
